# prototype/v2 — デザイン刷新「夜と翡翠」(2026-10-10)

クライアントサイドのデザイン一新用に作成された**5画面のデザインリファレンス**。
`prototype/`(v1・単一画面「新しいIntent」)の後継であり、デザインの正はこのv2側にある。

## 画面一覧

| フォルダ | 画面 | 主要ファイル |
|---|---|---|
| `01 預ける（ホーム）-html/` | 預ける(ホーム) — 入力と読み取りchips・待機中の意思一覧 | `Main.dc.html` |
| `02 読み解き確認-html/` | 読み解き確認 — あなたの言葉(ハイライト)・条件5行・人数確認・期限・預け方 | `Confirm.dc.html` |
| `03 待機中-html/` | 待機中 — メイン条件カード・カウントダウン・LATCHがしていること・取り下げ | `Standby.dc.html` |
| `04 候補が届く-html/` | 候補が届く — 照合表・回答期限・回答(参加/見送り+理由)・4状態 | `Proposal.dc.html` |
| `05 成立・チャット-html/` | 成立・チャット — 成立ヒーロー・メンバー・安全・チャット | `Latched.dc.html` |

各フォルダの `README.md` にもある通り、これらは**デザイン参照モックアップ**であり
production code ではない。複製すべき値(色・字号・余白・角丸・影・レイアウト)は
各 `.dc.html` のインライン `style` と `<helmet><style>` ブロックが正しい情報源。
`support.js`・`vendor/react*.js` はブラウザで表示するためのランタイムであり
デザインの一部ではない(5画面とも同一ファイル)。

`_backup-original/` はデザインツール上の改稿前の状態(経緯の記録)。実装の参照先は
上記5画面側。

## 見方

フォルダをHTTP配信して開く(一部ブラウザは file:// でスクリプトをブロックする):

```sh
cd prototype/v2
python3 -m http.server 8080
# http://localhost:8080/01%20%E9%A0%90%E3%81%91%E3%82%8B%EF%BC%88%E3%83%9B%E3%83%BC%E3%83%A0%EF%BC%89-html/Main.dc.html
```

画面間リンク・フォルダ名は相互参照(`../01 預ける（ホーム）-html/…`)で張られて
いるため、フォルダ名を変える場合はリンクの修正が必要。
