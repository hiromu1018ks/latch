## 運用ルール(合意事項)

1. 各文書の完成時に、要件定義書01の該当D-xxを解消済みへ更新する(トレーサビリティ維持)
2. 08は外部LLM契約(D-14)のリードタイムが長いため、03と並行着手できる
3. D-01/D-02は値そのものが運用データ待ちのため、09では「決め方の手順」を定める
4. D-18/D-20のような二重配置になり得る項目は、解消責任の所在を一つの文書に一元化する
5. 未決事項の決定は「決定内容/根拠/影響」の形式で文書化し、人間(プロダクトオーナー)が後から変更できる形で残す
