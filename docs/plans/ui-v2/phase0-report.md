1. ロードマップ・ギャップ分析・プロトタイプv2の5画面(`prototype/v2/01〜05`)・docs(00・01・02・03・05・12)・backend実装(reportsの理由4値・expiry-options・structured_dataの`extra="ignore"`・responses 3値)を確認し、D-01〜D-14の決定表(初版)を作成した
